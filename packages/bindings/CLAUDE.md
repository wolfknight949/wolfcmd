# @wolfcmd/bindings

**Purpose:** the TypeScript view of the Rust IPC: commands, events and types.

`src/index.ts` is generated by `tauri-specta` from `crates/wcmd-app` (`pnpm gen:bindings`; debug runs of the app keep it current). **Never edit it.** Change the Rust types and regenerate. Only `packages/app/src/core/` imports it.
