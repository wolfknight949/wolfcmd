# Changelog

WolfCmd releases (generated by `pnpm release`; edit a section before `publish` to change its notes).

## [0.8.0-beta.1] - 2026-10-15

A beta, still **not code-signed** (Windows SmartScreen may warn on first run: **More info → Run anyway**).

### Highlights
- **Undo and redo:** Ctrl+Shift+Z / Ctrl+Shift+Y, or the buttons next to the workspace switcher, undo closing, splitting, moving and renaming panels, tabs and workspaces. A closed panel or tab comes back with its shell or agent still running, screen and all.
- **No lost agents:** closing a panel, tab or workspace while an agent or command is running asks first (with "Don't ask again"); Ctrl+Q asks while agents run. Closing to the tray never asks.
- **A slate dark theme:** cool neutral greys, with terminals the darkest surface.

## [0.7.1-beta.1] - 2026-10-15

The first public release of WolfCmd: a beta, and **not code-signed yet** (Windows SmartScreen may warn on first run: **More info → Run anyway**). Signing through SignPath Foundation follows.

### Highlights
- **Workspaces and tabs:** one workspace per project, its tabs as pills along the top, restored exactly after a restart or a crash.
- **Tiled terminals:** split, resize, drag a panel onto another to move or swap it, maximize one, with a bundled Microsoft ConPTY for fast, correct output.
- **AI coding agents one click away:** Claude Code, Codex, Gemini CLI, Copilot CLI, Aider and OpenCode open from the Agents button. Claude Code and Codex sessions resume after a restart, and a spinner shows an agent at work, with a calm glow in its colour when it finishes.
- **Git worktrees per workspace:** work on several tasks in one repository side by side.
- **Find, links and command marks:** Ctrl+Shift+F, Ctrl+click on paths and URLs, jump between commands.
- **Plugins** add more agents with a small TOML file.
- **Close to the tray** (Ctrl+Q quits), dark and light themes, and a settings dialog.
- **Private by design:** no telemetry, no update checks; your data stays in `%APPDATA%\WolfCmd`.
